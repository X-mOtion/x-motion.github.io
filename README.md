# Beibei Jing — Academic Homepage

English academic homepage with publications, research projects, education, contact information, and 16 human motion demonstrations.

Website: https://x-motion.github.io/

## Update the website

Edit the HTML pages, `style.css`, or JavaScript files in this repository. Images, self-hosted Lato fonts, citation metadata, and motion videos are in `assets/`. GitHub Pages publishes the root of the `main` branch after each push. `.nojekyll` keeps the site as plain static HTML.

The site has four pages: `index.html` (Publications), `about.html`, `projects.html`, and `cv.html`. Motion previews are muted and loop while visible, with pause controls and support for reduced motion preferences.

## Sources and acknowledgments

Publication and citation data include their source links and verification dates on the website. Motion demonstrations come from the author's MoVT and RV2M project pages and academic presentation materials.
